# 11 — Roadmap (план развития)

Базис — Google Classroom, но с отличиями: файлы как истина, псевдонимы,
self-hosted, git-журнал. Приоритеты согласованы с заказчиком (2026-…).

## Выполнено

- Курсы, материалы (doc-плагин), задания, сдачи, оценки, обратная связь
- История версий сдач, тред комментариев к сдаче, вложения к сдаче
- SSE-уведомления (эфемерные, online-only)
- RBAC + **собственные роли** (`roles/*.yml`, admin UI)
- QR-вход
- git-журнал контента
- **Лента курса (stream)** — посты + комментарии, фильтр по группам
- **Журнал оценок (gradebook)** — сводная таблица + экспорт
- **Группы курса** — сущности, членство, видимость контента по группам
  (спека 12); UI: вкладки-группы, таблицы, добавление из ростера
- Админка пользователей: фильтры/пагинация на бэкенде
- Docker-образ в GHCR + `compose.prod.yml` + `DEPLOY.md`
- Тесты адаптера (`npm test`, node:test + jiti) и сид-данные (`npm run seed`)
- UI-кит: `BaseModal`/`SidePanel`/`IconBtn`/`ConfirmModal`/`SecretReveal`;
  URL — только иммутабельные id (спека 10)

## Ближайшие фичи (по приоритету)

### 1. Ведомости / сводки
Экспорт оценок (CSV/MD) и/или сводка курса для отчётности.

### 2. Quiz/survey плагины
Опросы и тесты как новый material/assignment-тип (specs/04-plugins.md).

### 3. Множественные учителя курса
`course.teacher` (строка) → список проверяющих; события уже адресуются
«автору курса» — расширить до «все с submissions.grade в курсе».

### 4. Расписание (спека 07)
Недельные слоты курса + месячный календарь с дедлайнами ДЗ.

## Закрытые вопросы

- **Группы (бывш. п.6):** реализовано как отдельные сущности `groups/<gid>.yml`
  с пересекающимся членством (union). Видимость контента — поле `groups`
  у материала/задания/поста: отсутствие = public, `[]` = «без группы»,
  список gid = только членам этих групп. См. `specs/12-groups.md`.

## Добавлено в план (2026)

### 5. Календарь
- Для учителя и учеников: очные занятия + дедлайны ДЗ.
- Свой календарь (без внешней интеграции на первом этапе).
- Источники событий: расписание занятий (новая сущность `schedule` в курсе?),
  `assignment.due`.
- Позже: синхронизация с Google Calendar и Яндекс.Календарём
  (iCal feed — самый дешёвый путь: публиковать .ics-эндпоинт).

## Отложено / вне скоупа

- Родительский доступ (guardian summaries) — не нужно по модели продукта.
- Антиплагиат (originality reports), аудио/видео-фидбек, мобильное приложение,
  интеграции Workspace/Gemini.
- Персистентные уведомления — пока осознанно ephemeral (офлайн = не видит).
