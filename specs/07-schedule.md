# Расписания: недельное (курс) и месячное (календарь)

Согласованный приоритет: реализуется **сразу после ДЗ-цикла** (шаги 3–4),
потому что месячный календарь включает дедлайны заданий.

## Два представления, один источник

### 1. Недельное расписание курса (recurring slots)

Каждый курс имеет шаблон регулярных занятий — файл:

```
content/courses/<slug>/schedule.yml
```

```yaml
slots:
  - weekday: 2          # 1=пн ... 7=вс
    time: "18:00"       # локальное время, без таймзоны (см. ниже)
    durationMin: 60
    note: "ОГЭ-тренажёр"
```

- Редактирует учитель курса (или админ) на странице курса.
- Пустой/отсутствующий файл = занятий нет.
- Мутации через ContentStore → git-журнал бесплатно.

### 2. Месячный календарь (вычисляемый)

НЕ хранится в файлах — это проекция, собираемая на лету из:

| Источник | Событие |
|---|---|
| `schedule.yml` всех курсов пользователя | регулярные занятия в днях месяца |
| `assignments/*/assignment.yml` | дедлайны ДЗ (тип «дедлайн», ссылка на задание) |
| `schedule.yml → overrides` | исключения: отмена, перенос (новая дата/время), доп. занятие |

```yaml
overrides:
  - date: "2026-11-16"      # слот, который меняется
    type: cancel            # cancel | move | extra
    to: { date: "2026-11-18", time: "18:00" }   # для move
    note: "Перенос из-за праздника"
```

Overrides хранятся в `schedule.yml` того же курса (журналируются, видны в git).

## API

- `GET  /api/courses/<slug>/schedule` — слоты курса (+ запись для управления)
- `PUT  /api/courses/<slug>/schedule` — сохранить слоты (владелец/admin)
- `POST /api/courses/<slug>/schedule/overrides` — добавить исключение
- `GET  /api/calendar?month=YYYY-MM` — события месяца для текущего пользователя:
  учитель — по всем своим курсам; ученик — по всем курсам, где зачислен.

## UI

1. **Страница курса** — блок «Недельное расписание»: редактируемая сетка
   (день недели, время, длительность, заметка) для учителя; для ученика — read-only.
2. **Страница `/calendar`** — месячная сетка (пн–вс): занятия и дедлайны
   с цветовой маркировкой; переключение месяцев; ссылка из шапки.
   Учитель видит свои курсы, ученик — свои; события подписаны курсом.

## Решения и ограничения

- **Время без таймзоны** — платформа для РФ, считаем локальное время сервера;
  таймзоны не вводим (принцип «минимум движущихся частей»). Пересмотр — только
  если появятся ученики из других поясов.
- Дедлайны, наступившие «сегодня», — отдельный блок «Сегодня» над сеткой.
- Конфликтующие слоты у учителя (два курса в одно время) НЕ запрещаются —
  подсвечиваются в календаре.
- Напоминания/уведомления — вне скоупа этой спеки (см. 05, post-MVP).
