# Квизы («Закрепление материала») внутри темы

> **Статус: реализуется.** Самопроверка ученика по теме: тесты с
> автопроверкой, привязанные к материалу. Отдельно от заданий — это
> неоцениваемая практика; результаты копятся в личной статистике ученика.

## Концепция

Учитель в редакторе темы видит блок **«Закрепление материала»** под
ссылками. Там создаются проверки (квизы) — их может быть несколько на тему.
Ученик, имеющий доступ к теме, проходит квиз целиком и сразу получает
авто-оценку с разбором. Попытки анонимны для других учеников, но
сохраняются в данных ученика (фундамент для личного дашборда/геймификации).

## Модель данных

```
materials/<id>/
  quizzes/<qid>.yml               # определение квиза
  quizzes/<qid>/answers/<username>.yml   # попытки ученика
```

`quizzes/<qid>.yml`:

```yaml
id: qz_a1b2c3
title: Проверка по теме
type: quiz
showAnswers: true          # показывать правильные ответы после сабмита
createdAt: ...
updatedAt: ...
questions:
  - id: q1
    type: single           # single | multi | truefalse | fill | order
    prompt: "2 + 2 = ?"    # markdown
    points: 1
    options:               # single/multi/truefalse
      - { id: a, text: "3" }
      - { id: b, text: "4" }
    correct: b             # single/truefalse — id варианта; multi — [id,...]
  - id: q2
    type: fill
    prompt: "Столица Франции — {{1}}"
    points: 2
    blanks:
      - answers: ["париж", "paris"]
  - id: q3
    type: order
    prompt: "Расставьте по порядку"
    points: 1
    items: [{ id: i1, text: "шаг 1" }, ...]
    correctOrder: [i1, i2, i3]
```

`answers/<username>.yml`:

```yaml
username: uch-01
attempts:
  - submittedAt: 2025-...
    answers: { q1: "b", q2: ["париж"], q3: ["i1","i2","i3"] }
    score: 4
    total: 4
```

## Авто-оценка (сервер, единственный арбитр)

- `single`/`truefalse`: ответ = id варианта, совпал с `correct` → points.
- `multi`: каждый верно выбранный +часть, каждый ошибочно выбранный −часть;
  балл = points × (верные − ложные) / |correct|, клэмп [0, points].
- `fill`: blank принимается, если введённое (case-insensitive, trim,
  схлопнутые пробелы) совпадает с любым из `answers`.
- `order`: балл = points × (длинаLongestCommonSubsequence / n) —
  частичный кредит за порядок.
- Неотвеченный вопрос = 0. Результат и правильные ответы отдаются
  только после сабмита; `showAnswers: false` — только score/total.

## Права и видимость

- CRUD квизов — `materials.edit` (учитель — свои курсы).
- Список/прохождение — любой, кто видит тему (`loadMaterialForRead`
  + groups-фильтр темы наследуется автоматически).
- Попытки: ученик видит только свои; учитель (`materials.edit`) — все.
- Ученический ответ API **не содержит** `correct`/`correctOrder`/
  `answers` blanks до сабмита (toStudentQuiz стрипает решения).

## API

```
GET    …/topics/<id>/quizzes                    # сводки + мой лучший балл
POST   …/topics/<id>/quizzes                    # создать
GET    …/topics/<id>/quizzes/<qid>              # полный квиз (учитель) / стрипнутый (ученик)
PATCH  …/topics/<id>/quizzes/<qid>
DELETE …/topics/<id>/quizzes/<qid>
GET    …/topics/<id>/quizzes/<qid>/attempts     # ученик: свои; учитель: все
POST   …/topics/<id>/quizzes/<qid>/attempts     # сабмит { answers } → оценка+разбор
```

## UI

- Тема: блок «Закрепление материала» под ссылками — список квизов
  (название, число вопросов, для ученика — лучший балл/попытки,
  для учителя — управление и число попыток).
- Прохождение — отдельная страница
  `/courses/<c>/topics/<id>/quizzes/<qid>`: вопрос за вопросом,
  прогресс, «Проверить» в конце → экран результата (балл, разбор,
  по желанию правильные ответы).
- Редактор — крупная центрированная `BaseModal`: список вопросов,
  добавление по типам-заготовкам, inline-редактирование, drag-sort,
  баллы за вопрос, `showAnswers`.
- Результаты учителя — в блоке «Закрепление»: напротив квиза
  раскрываемый список попыток (ученик, балл, дата, число попыток).

## Не входит (сознательно)

- Открытые вопросы (essay/short) — только автопроверка.
- Баллы в журнал оценок — квиз информативный.
- Дедлайны, анонимность попыток для учителя, группировка попыток
  по группам — пока нет.
