# Классная комната (klassroom) — обзор проекта

## Что это

Self-hosted платформа для дистанционных занятий в духе Google Classroom, но без
избыточности полноценной LMS. Целевая аудитория — репетиторы и малые группы
преподавателей (2–10 учителей), которым существующие решения кажутся
перегруженными, коммерциализированными или непригодными для self-hosted
и работы из России.

## Ключевые принципы

1. **Файлы — источник истины.** Всё состояние платформы хранится в файлах
   (markdown + YAML frontmatter + вложения). Git используется как журнал
   истории и транспорт бэкапа, но НЕ как источник данных (см. `03-git-journal.md`).
2. **Приватность по дизайну.** Никаких персональных данных: нет email, телефона,
   реальных имён. Аккаунт = псевдоним + пароль. Соответствие «реальный человек ↔
   псевдоним» живёт вне системы. Без аналитики и без логирования IP.
3. **Минимум движущихся частей.** Один Node-процесс (Nuxt 4 + Nitro). Никаких
   внешних сервисов: почты, облаков, отдельной БД, системного cron.
4. **Расширяемость с первого дня.** Плагинная система «типов материалов»:
   сегодня — документы (md), завтра — тесты, анкеты и т.п. (см. `04-plugins.md`).
5. **Сменяемое хранилище.** Доступ к данным только через доменные порты
   (repository-паттерн); файловый адаптер — первый, SQLite-адаптер возможен
   позже без переписывания роутов и фронта (см. `01-architecture.md`).

## Терминология

| Термин | Значение |
|---|---|
| Курс (course) | Объединяет понятия «класс» и «предмет». Один курс = один учитель (в MVP) |
| Материал (material) | Единица учебного контента в курсе. Имеет `type`, обрабатывается плагином |
| Тема (doc) | Первый тип материала: md-документ-конспект |
| Задание (assignment) | ДЗ: описание, дедлайн, шкала оценивания, статус |
| Сдача (submission) | Ответ ученика на задание: текст md + файлы + статус + оценка |
| Псевдоним (pseudonym) | Публичное имя аккаунта, не раскрывающее личность |
| Журнал (git journal) | Дебаунс-автокоммиты в git-репозиторий контента |
