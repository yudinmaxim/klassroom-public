# Группы внутри курса и видимость контента

> **Статус: реализовано.** Группы — отдельные сущности курса; контент
> (темы, задания, посты ленты) фильтруется по видимости. Сервер — источник
> истины, фронт только прячет недоступное.

## Сущность

`content/courses/<courseId>/groups/<gid>.yml`:

```yaml
id: grp_a1b2c3        # иммутабельный, = имя файла/директории
course: <courseId>
title: Сильные
members: [uch-01, uch-02]   # username'ы из roster курса
createdAt: 2025-...
```

- Членство **пересекается**: ученик может состоять в нескольких группах
  курса и в нескольких курсах; эффективное множество групп — union.
- Удаление группы каскадно очищает её id из `groups` тем/заданий/постов
  (→ «без группы») и из `members` не требуется — зомби-чистка при
  исключении ученика из курса.
- Membership проверяется только против roster курса (не-участник → 400).

## Видимость контента: поле `groups`

У материала, задания и поста ленты есть опциональное поле `groups`:

| Значение | Смысл |
|---|---|
| отсутствует / `undefined` | **legacy → public**: видят все участники курса |
| `[public]` | public: все участники |
| `[]` | «без группы»: ученикам скрыто, учителю/менеджерам видно |
| `[gid1, gid2]` | только ученикам, состоящим хотя бы в одной из этих групп |

- **Ученики** видят сущность, если она public ИЛИ её `groups` пересекается
  с их эффективными группами (`viewerGroupIds`).
- **Учителя/менеджеры** видят всё (read-сторона не фильтрует).
- Пустой `groups` в API-запросе создания трактуется как «не указано» →
  `[public]`; явное «скрыть от всех» делается через `[]`.

### Задания — пересечение с audience

Видимость сдачи = `audience` (все/выбранные) **∩** группы:

- задание `audience: all` + `groups: [gid]` → сдают только члены gid;
- `audience: chosen` + `groups: [gid]` → только выбранные ∩ gid;
- public-задание (`groups` отсутствует) → все участники по audience.

### Лента

- `GET stream` фильтрует посты по `contentVisibleToGroups`.
- Постить ученик может только в public или в свои группы (`groups` поста
  обязан пересекаться с его группами; чужая/несуществующая → 400).
- Комментарии поста наследуют видимость поста (404 на чужой групповой пост).

## Права

- Управление группами — пермишен `courses.groups.manage`
  (учитель — только свои курсы, админ — все).
- Состав групп и их названия сейчас видны любому участнику курса через
  `GET …/groups` — осознанное решение MVP; ужесточение (ученику — только
  свои группы) — открытый вопрос приватности.

## UI

- Вкладка «Группы» — nested routes: обзор-таблица + страница группы
  (`groups.vue` layout + `GroupsToc`, как у тем). Группы — под-вкладки.
- Таблица «Учащиеся» показывает чипы групп и row-action «В группу»
  (добавить в существующую / создать новую).
- Редакторы темы/задания/публикация — `GroupField` (чекбоксы групп).
